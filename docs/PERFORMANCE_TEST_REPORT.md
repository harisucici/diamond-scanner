## 测试命令

```bash
# 安装测试依赖
npm install vitest --save-dev

# 运行所有测试
npm test

# 运行单元测试
npm run test:unit

# 运行集成测试
npm run test:integration

# 运行性能测试
npm run test:performance

# 生成覆盖率报告
npm run test:coverage

# 监听模式（开发时）
npm test -- --watch
```
